Features

Thirteen switches. One editor.

Every tool lives in the toolbar panel and adds a focused upgrade to the costume editor. No new app, no new project format.

01

Vector bitmapping

A separate pixel-art window with nine tools, a palette, zoom and undo. It writes real vector paths, so the art stays sharp when the sprite scales.

02

31 shape tools

Arm a shape and drag. Triangles, stars, arrows, hearts, clouds and speech bubbles, with size and corner rounding.

03

Pen and nibs

Six pressure profiles plus free thickness. Use [ and ] or Alt + wheel to change the nib without leaving the canvas.

04

Animation anchor

Measures the pivot jump between costumes and writes a shared centre in one click. Only the rotation centre changes.

05

Layer rail

Pick, hide, lock, rename and reorder objects from the right edge of the canvas. Align, rotate, duplicate and set opacity.

06

Masks and blend

Clip a shape inside another, cycle 16 blend modes, fix thick-outline spikes and export a transparent PNG at 1×, 2× or 4×.

07

Plan board

To do, Doing and Done columns with draggable cards. Stored in your browser, exported as JSON; never written into the project file.

08

Gradient stops

Two-, three- and four-stop gradients inside the editor's own colour box, written as native SVG gradients.

09

Load diet

Slower idle polling, no work in a background tab and an optional analytics blocklist. Turn it off to restore the flat 900 ms loop.

10

Sprite folders

Group sprites into folders above the sprite list. A folder filters the pane; costumes, scripts, layer order and the project file stay untouched.

Install

Load it once. Keep drawing.

No build step and no package manager. Chrome, Edge, Brave and Opera are supported.

01

Download the repository

Use Code → Download ZIP on GitHub and extract it, or clone the repo.

02

Open the extensions page

Go to chrome://extensions. Edge, Brave and Opera use their own scheme.

03

Turn on Developer mode

The switch is in the top-right corner of the extensions page.

04

Click “Load unpacked”

Select the extension folder — the one that contains manifest.json. Not the repository root.

05

Pin the extension

Use the puzzle-piece icon in the toolbar and pin ScratchDream for quick access to the switches.

06

Refresh the editor

Press F5 on the Scratch, TurboWarp or PenguinMod tab, then open Costumes.

Download on GitHub

Updating: replace the files in the extension folder, click the reload icon on the ScratchDream card in chrome://extensions, then refresh the editor tab.

Privacy

No account. No server of ours. No telemetry.

The extension is deliberately boring about data.

What it asks for

  • storage — feature switches and the plan board's and folders' local state.
  • declarativeNetRequest — the optional analytics blocklist used by Load diet.
  • No host permissions. Content scripts run only on the supported editor domains and localhost.
  • What it calls: Scratch's own pages and API for the panels, Google fonts and ForumFind for the forum skin and its search. Nothing else.

What it never does

  • No background worker, no analytics, no AI keys.
  • No uploads. Your art stays in the project file.
  • No plan-board data in the project. It lives in localStorage; export it for a backup.
