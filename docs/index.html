Everything you imagine, in Scratch.

ScratchDream upgrades the costume editor in Scratch, TurboWarp and PenguinMod with vector pixel art, 31 shapes, pressure nibs, masks, a layer rail, a plan board and one-click animation anchors — inside the editor you already know.

What's inside

  • Vector bitmapping that never blurs
  • 31 shapes + 6 pressure nibs
  • Masks, 16 blend modes, transparent PNG
  • Layer rail with hide, lock and reorder

Features

Nine switches in the toolbar panel. Each one adds a focused tool to the costume editor — no new app, no new project format.

◩

Vector bitmapping

A separate pixel-art window with nine tools, a palette, zoom, undo and edge cleanup. Writes real vector paths, not a bitmap costume.

▲

31 shape tools

Arm a shape and drag. Triangles, stars, arrows, hearts, clouds, speech bubbles and more, with size and corner rounding.

✎

Pen and nibs

Six pressure nib profiles plus free thickness. Use [ ] or Alt + wheel to change the nib.

◎

Animation anchor

Measures the pivot jump between costumes and writes a shared centre in one click. Only the rotation centre changes.

▤

Layer rail

Pick, hide, lock, rename and reorder objects. Align in six directions, rotate ±90°, duplicate, delete and set opacity.

◐

Masks and blend

Mask a shape inside another, cycle 16 blend modes, adjust the miter limit and export transparent PNG at 1×, 2× or 4×.

▦

Plan board

To do / Doing / Done columns with draggable cards. Stored in your browser; export and import as JSON.

◒

Gradient stops

2, 3 and 4-stop gradients inside the editor's own colour box, written as native SVG gradients.

⚡

Load diet

Slower idle polling, no background work and an optional analytics blocklist. Turn it off to restore the flat 900 ms loop.

Install

No build step, no package manager. Load the extension folder as an unpacked Chrome extension.

1

Download the repository

Use Code → Download ZIP on GitHub and extract it, or clone the repo.

2

Open the extensions page

Go to chrome://extensions (Edge: edge://extensions, Brave: brave://extensions).

3

Turn on Developer mode

The switch is in the top-right corner of the extensions page.

4

Click “Load unpacked”

Select the extension folder — the one that contains manifest.json. Do not select the repository root.

5

Pin the extension

Use the puzzle-piece icon in the toolbar and pin ScratchDream for quick access to the switches.

6

Refresh the editor

Press F5 on the Scratch, TurboWarp or PenguinMod tab, then open the Costumes tab.

Updating: replace the files in the extension folder, click the reload icon on the ScratchDream card in chrome://extensions, then refresh the editor tab.

Privacy

No account, no server, no telemetry. The extension is deliberately boring about data.

What it asks for

  • storage — feature switches and the plan board's local state.
  • declarativeNetRequest — the optional analytics blocklist used by Load diet.
  • No host permissions. Content scripts run only on the supported editor domains and localhost.

What it never does

  • No network requests, no background worker, no AI keys.
  • No uploads. Your art stays in the project file.
  • No plan-board data in the project. It lives in localStorage; export it for a backup.
